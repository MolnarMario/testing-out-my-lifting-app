# Ironlog — Powerlifting Tracker

A self-contained powerlifting tracker web app. The entire application lives in a single file, [`index.html`](index.html) — just open it in a browser to run it.

## Usage

Open `index.html` in any modern web browser. No build step or server required.

**Play it live: https://molnarmario.github.io/testing-out-my-lifting-app/**
